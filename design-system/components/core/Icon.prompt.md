Ícone Lucide — é a única família de ícones da Ativa (`lucide-react` no CRM, `iconLibrary: "lucide"` no components.json).

```jsx
<Icon name="map-pinned" size={24} color="var(--primary)" />
<Icon name="chevron-right" size={20} base="../../assets/icons/" />
```
